# 私有仓库统计实现验证

## 授权与范围

首版采用用户单独提供的 fine-grained
PAT，不扩大现有登录 OAuth 权限，不要求新增 GitHub
App。界面指引用户选择一个资源所有者、指定仓库、有效期及 Contents/Metadata 只读权限，并说明组织审批和协作者限制；服务器只执行读取操作，但不能从令牌前缀证明没有额外写权限。

每次连接、读取结果或启动任务都检查令牌对应的 GitHub 数字身份与原主账号一致，以及所选仓库的身份、私有性和 Contents 访问权。首版明确选择最多十个私有仓库，独立手动刷新，仅按主账号的主要作者统计默认分支最近一年历史，单仓库最多五万条提交。

## I-AC01：授权选择与采集可验证

Worker 回归覆盖令牌类型、身份不匹配、组织拒绝、仓库可见性变化、空仓库、分页、作者匹配及完整快照发布。私有任务具有独立十五分钟冷却和最多四个并发槽，不修改公开任务或定时采集行为。

## I-AC02：数据与缓存边界可验证

凭据使用带用户与用途绑定的加密命名空间。私有选择、凭据和聚合快照只存于独立的用户表，不写入原有仓库、提交、历史缓存、公开快照或公共 KV。测试覆盖匿名和跨用户拒绝、同源变更保护、读取时重新授权、撤权隐藏、断开删除、替换授权与旧任务竞争。

替换授权或选择时删除旧快照并更换 generation；断开删除整行。旧任务不能恢复已删除的数据或覆盖新授权。GitHub 撤权或检查失败后不返回旧结果；已有服务器数据保留到重新连接或断开，不承诺删除历史备份或召回用户已经下载的数据。

页面请求失败会清空私有结果。发布前复核补充了断开时取消旧请求以及配置面板与仪表盘同步的回归测试，防止晚到的响应重新显示旧数据。

## I-AC03：公开功能保持兼容

公开主页与兼容 API 继续读取原来的公开快照，私有统计不参与公开 totals、yearly 或 rolling。公共投影明确拒绝带私有标记的快照；回归验证公开结果保持独立。私有 Workflow 只保存非敏感检查点结果，失败消息不包含仓库或提交内容。

验证入口为
`pnpm check`，覆盖格式、发布脚本、lint、类型、测试及构建；私有 Worker 和 Workflow 定向测试，以及私有界面定向测试亦已执行。
