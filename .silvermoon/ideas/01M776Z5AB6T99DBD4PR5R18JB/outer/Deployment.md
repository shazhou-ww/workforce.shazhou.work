# Deployment

本契约为准备阶段的可调整现实世界初版，不代表获得生产部署授权。

## Steps

### D-S01: 确认上线配置与迁移保障

在上线前确认管理员稳定身份、邮箱验证能力、资源预算，以及现有公开看板归属、数据备份和迁移恢复路径。

### D-S02: 按授权流程发布

仅在明确获得生产发布授权后，集成最新主线并通过检查，使用新 Release 标签触发现有 GitHub
Actions 部署流程，不从本地直发生产。

### D-S03: 验证真实邀请与个人隔离

使用经授权的管理员和测试账号验证真实登录、邀请领取、个人统计、停用效果与现有公开页面，记录不含敏感数据的验证证据。

## Acceptance criteria

### D-AC01: 现有服务未被覆盖

通过迁移前后生产页面、API 与既有统计样本对照，证明原公开看板仍可访问且未被新用户结果覆盖。

### D-AC02: 邀请授权实际生效

用真实登录验证受邀、未受邀、缺失可信邮箱和停用状态；直接访问 API 及已有会话均服从授权，任务调度不继续服务停用用户。

### D-AC03: 发布与资源状态可核验

部署工作流成功，生产 API 和 UI 检查通过，并能从受保护的任务与配额信息确认资源限制生效，不暴露凭据或用户邮箱。
