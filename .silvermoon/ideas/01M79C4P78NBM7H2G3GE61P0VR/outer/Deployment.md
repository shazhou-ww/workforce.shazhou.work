# Deployment

## Steps

### D-S01: 准备外部授权与受控验证

落实选定授权方案所需的应用配置和企业审批，使用明确获准的测试仓库与账号；不把真实凭据或私有仓库内容写入跟进文档。

### D-S02: 按生产流程发布

取得明确发布授权后，同步最新主线并通过检查，使用新的 Release 标签触发现有 Cloudflare 工作流；准备功能关闭和数据处置方案。

### D-S03: 验证线上访问及撤权

核对本人统计、跨用户和匿名访问、公开主页及权限撤销后的实际行为。

## Acceptance criteria

### D-AC01: 线上授权与统计可用

以获准账号完成选仓和采集，确认私人统计可见；保留脱敏的验证结果。

### D-AC02: 线上私有边界有效

使用另一账号及匿名访问验证公开输出无私有信息或统计；撤销授权后确认停止采集且旧数据遵守约定规则。

### D-AC03: 发布与现有功能正常

确认部署工作流成功、生产 API 与 UI 正常、公开仓库和分享功能可用，并记录已验证的关闭及数据处置方式。
